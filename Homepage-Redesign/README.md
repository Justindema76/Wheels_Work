# Wheels homepage redesign

One folder per homepage section, top to bottom.
**`-CODE` / `-CSS` files = paste into Magento. `-PREVIEW` files = open in a browser to look.**

| Folder | What's in it |
|---|---|
| `1 HERO` | Hero CSS (Safari-safe, class `whero`) + Code Studio slider code + preview |
| `2 SHOP BY CATEGORY` | Category grid code (Page Builder columns, classes `wcat-*`) + preview; `MEETING OPTIONS/` = 4 design options |
| `3 POPULAR PRODUCTS` | Your original product-row CSS + the slowed-down slider script |
| `4 SAVINGS BANNER` | "Combine them on every order" banner code + preview |
| `5 DEAL TILES` | Deal tiles CSS (Products element, class `wdeal`) + preview |
| `6 SITE STYLES` | Section headings + 1320px site width (desktop only) |
| `7 PROMO STRIP` | 4 promo tiles from Page Builder columns (classes `wpromo-*`), each linked to a category you pick + preview |
| `PLAN + HANDOFF` | Full homepage plan preview, boss pictures, navbar file for the developer |
