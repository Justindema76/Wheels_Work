Homepage class list

Every CSS class we made for the homepage blocks, and what it does. The look of all of them comes from one theme file, wheels-homepage.css, so the blocks only need the class names.

Where to type them: click the element in Page Builder → ⚙ (settings) → Advanced → CSS Classes.
More than one class: separate them with a space, never a comma. Example: wcat-card wcat-i-flags
Works on: rows, columns, headings, text, buttons and Products elements.

Which website it shows on

Put one of these on any row, column, heading, text, button or Products element. It then shows only on that website and is hidden on the others.

ClassShows onHidden on
lang-enCanada English + USFrench
lang-frFrench onlyCanada English + US
lang-caCanada English onlyFrench + US
lang-usUS onlyCanada English + French
Typical use: put the English text and the French text side by side in the same column, with lang-en on one and lang-fr on the other. One block then works for all three websites.
Not possible with these: "both Canada sites but not US". Ask for a hide-on-us class if you need it.
