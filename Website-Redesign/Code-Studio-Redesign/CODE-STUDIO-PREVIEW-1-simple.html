What's different from the current Code Studio

  • Publish instead of copy & paste. Today every change means Copy embed code, then paste into Magento for each site. If someone forgets, the website shows an old version. Publish updates all 3 sites in one click.
  • Previews you can trust. Today the Mobile canvas is 390px wide, but on wheelsauto.com phones the banner is 345px, so pictures crop differently. Here both previews use the website's real sizes, side by side.
  • Phone picture warnings. Today a slide can quietly use the desktop picture on phones (the Podiums slide does). Here you get a warning on the slide and in Images.
  • Phone layout choice. "Photo on top, text below" keeps text readable on any photo.
  • 3 simple tabs instead of 6. Text, Images and Look. Fine-tuning lives under Advanced.
  • Desktop and phone stay linked. Today phone copies desktop once and then drifts. Here text and style are shared, and only the phone picture and phone layout are separate.
  • Clear EN / FR / USA status. An orange dot means the French text still needs translating.
  • A short top bar. One main button (Publish). Everything else is under More.
